## Projet Principal

### Mealo Planner

  ```Développement full-stack``` ```Intégration de LLM / IA générative```

Une application web qui permet de découvrir de nouvelles recettes grâce à de l’intelligence artificielle générative, <br/> d’organiser ses repas au quotidien  et de simplifier ses courses.

- Découverte de recettes assistée par IA (LangChain / LangGraph)
- Planification de menus et listes de courses optimisées
- Application multi-tenant (espaces partagés, rôles)
- Qualité logicielle : tests, CI/CD

Environnement technique :<br/>
React, TypeScript, Inertia.js, TanStack Form, Zod, Zustand, Storybook, PHP, Laravel, Eloquent ORM, Pest, PostgreSQL, AdonisJS, LangChain, LangGraph, GitHub Actions, Docker

Liens : [Démonstration](https://mealo.lioneldev.fr/demo/LtMUhxAYiog) · [GitHub](https://github.com/lionelp-dev/Mealo)
